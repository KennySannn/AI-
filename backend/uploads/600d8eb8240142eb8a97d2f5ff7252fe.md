

# 国内Agent Skills仓库清单（全带可直接访问URL）

1. **baoyu-skills（自媒体内容生产专用技能）**
   https://github.com/JimLiu/baoyu-skills
   PPT、图文、短视频、小红书/公众号分发、信息绘图技能

2. **awesome-agent-skills**

   https://github.com/libukai/awesome-agent-skills  （中文技能资源导航合集）

   https://github.com/VoltAgent/awesome-agent-skills  （国外技能资源导航合集）
   汇总全球+国内所有Agent Skill、工具模板、MCP服务

## 国内在线技能市场（网页端，无需翻墙，国内CDN加速）
1. **腾讯SkillHub（国内官方技能商店）**
   https://skillhub.tencent.com/
   3万+中文Skill，一键安装，适配OpenClaw/QClaw

2. **SkillsMP 中文站**
   https://skillsmp.com/zh
   40万+全球技能同步，中文标签筛选，预览Skill源码

3. **微步SafeSkill政企安全技能库**
   https://safeskill.cn/skillHub
   带安全审计的技能仓库，适合政务、企业内网场景

4. **藏云阁Agent Skill镜像仓库**

   http://cncfstack.com/skills
